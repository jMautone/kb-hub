# Storefront notes

- Run the app locally with `npm run dev:all`; it starts cart, checkout and the web app.
- Payment sandbox credentials are in the team password manager, never in this vault.
- Feature branches follow `feature/<work item>-<slug>`, bug fixes `bugfix/<work item>-<slug>`.
